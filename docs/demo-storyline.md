# Career GenUI 对外演示故事线

## 一句话故事

一名正在备考 CPA 会计、并计划应聘审计助理或财务分析岗位的用户，需要在每周 3 小时的有限时间内补齐长期股权投资等知识缺口，并把学习过程转化为可以在简历和面试中验证的职业证据。Career GenUI 不是替用户“生成一堆页面”，而是在主模型判断纯文本不足以完成任务时，临时生成最小充分界面，帮助用户选择、练习、确认和提交。

## 6 幕展示动线

### 1. 角色与目标

- 角色：有基础财务经历、正在备考 CPA 会计，但知识结构、会计判断和表达证据不完整的候选人。
- 目标：补强长期股权投资与内部交易处理能力，并形成可用于审计 / 财务岗位匹配、简历和面试的证据。
- 约束：每周可投入时间有限，不能从头学习一套完整课程。

### 2. 问题升级

- 传统聊天可以回答问题，但答案不会自动进入练习、计划和职业材料。
- 学习工具能刷题，但不会把结果转成项目证据。
- 求职工具能改简历，却不了解用户刚刚完成的学习和练习过程。

### 3. 主模型判断

主模型先理解用户目标。若文本可以直接完成任务，则继续自然语言回复；只有当任务需要选择、比较、修改、连续执行或确认写回时，才委派给 GenUI。

### 4. 学习闭环

诊断 → 材料 → 理解 → 练习 → 检验复盘

每一阶段都必须说明：

- 为什么此时出现这个界面；
- 用户要完成什么动作；
- 哪个结果会被确认；
- 结果如何改变下一步。

### 5. 证据转译桥

阶段复盘不是终点。系统识别出“已经掌握的能力、仍需补强的错因、可证明的项目经历”，并询问用户是否把这些结果转为岗位准备。用户确认后，职业闭环才开始。

### 6. 职业闭环与结果

资料 → 岗位 → 案例 → 面试 → 证据沉淀

最终结果不是一个总分，而是：

- 已验证能力；
- 仍缺少的证据；
- 可复用的项目表达；
- 下一轮补强任务；
- 更新后的成长状态。

## 主模型进入 GenUI 的决策链

```text
用户消息
  → 元宝主模型理解意图与上下文
  → 先判断文本能否直接完成任务
      ├─ 能：自然语言回答，必要时给来源
      └─ 不能：进入 GenUI 资格判断
            → 是否存在有意义的用户操作
            → 是否存在可校验的结构
            → 是否需要工具结果或多步执行
            → 结果是否需要用户确认并写回
            → 风险与端侧空间是否允许
                ├─ 不满足：追问 / 轻量确认 / 文本降级
                └─ 满足：生成 Artifact Plan
                      → Schema 校验
                      → 选择消息卡 / Sheet / 全屏工作台
                      → 工具与模型协作执行
                      → 用户确认
                      → State Patch
                      → 主模型回到对话，解释结果并发起下一步
```

核心原则：

- 主模型始终拥有对话主导权。
- GenUI 是主模型临时委派的任务工作台，不是另一个割裂的聊天机器人。
- 没有用户确认，不写长期状态。
- 任务完成、风险升高或结构不充分时，退出 GenUI 并回到主模型。

## 演示模式

故事线是对外展示的推荐入口，不是产品的信息架构替代品。四阶段能力导航和 21 项能力卡继续完整保留，观众既可以沿故事线体验，也可以跳到任意功能独立操作。Sheet、全屏工作台、状态恢复、撤销、清空、资料、考试、面试和证据编辑等原有能力不因故事线而裁剪。

### 自动体验

- 适合首次浏览完整故事。
- 每阶段遵循“用户意图 → thinking → 界面 → 操作 → 局部反馈 → 写回 → 接力”。
- 允许暂停，暂停后不保留未完成 timer。

### 手动逐步体验

- 适合面试讲解。
- 每次只推进一个阶段。
- Artifact 内部仍可自由操作。
- 不运行自动脚本；资料载入、打开全屏工作台、选择、作答、校验和提交都由演示者触发。
- 点击“下一阶段”前不自动跳转。

## 演示成功标准

- 观众在 30 秒内知道“谁在用、要完成什么”。
- 观众能说清楚主模型为什么在某一步进入 GenUI。
- 每阶段都有可见的用户动作和写回结果。
- 学习闭环到职业闭环有明确因果桥接。
- 自动与手动模式都不会产生重复回复或重复 Artifact。
- 页面不暴露控制脚本、开发者提示或播放时长。
