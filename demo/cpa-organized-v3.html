CPA 诊断三层泳道

横轴是用户流程，纵轴说明每个阶段由谁完成什么动作。

层级任务触发画像确认原因定位行为验证生成诊断行动分流状态回写
用户层表达困惑说一句不完整的话即可。点击确认选择或修改科目、章节、时间。回答选择题指出最常见的卡点。完成短题用真实行为补充自评。查看结果理解结论、依据与置信度。选择动作复习、专项题或继续新章。查看变化确认学习画像已更新。
策略层任务路由识别薄弱点诊断与进度决策。字段筛选只确认高影响、低置信度信息。卡片排序选择区分度最高的原因卡。验证决策判断历史记录是否足够。规则校准分项评分、风险与不确定项。动作编排限制为最多三个下一步。接力判断决定是否复诊与更新计划。
数据与模型层意图与字段抽取识别科目、章节和问题。画像与历史记录读取进度、正确率和时间。错因分类区分概念、分录、计算、整合。题库与知识映射选择最小区分性题目。诊断规则＋解释模型规则定边界，模型负责解释。内容与任务生成匹配解释、练习或计划。状态与证据存储写入来源、时间和置信度。
02

卡片投放与诊断决策

不是固定问卷，而是根据当前状态选择信息价值最高的一张卡。

候选卡片如何排序

诊断影响答案是否会改变“继续学习还是先复习”的结论。
当前不确定性系统是否缺少信息，或推断置信度较低。
行动相关性答案是否会改变题型、复习方式或优先级。
用户负担是否值得再问，能否用 4—6 个选项完成。

投放顺序

① 目标不清楚：投放任务分流卡。

② 信息已有但不确定：投放预填确认卡。

③ 多个原因无法区分：投放错因区分卡。

④ 自评与历史数据冲突：投放短验证题。

⑤ 信息足够：停止追问，直接输出诊断与行动。

03

三类专项策略

通用机制之上，CPA 场景需要单独配置追问、验证和停止条件。

MINIMUM QUESTIONING

最少追问

  • 已确认的信息不重复问。
  • 只问可能改变结论的字段。
  • 单轮连续选择卡不超过 3 张。
  • 无法选择时才开放自由输入。
BEHAVIOR VALIDATION

行为验证

  • 用户不确定错因时投放 1 道题。
  • 自评与历史正确率冲突时优先验证。
  • 基础题正常、综合题波动时投放跨知识点题。
  • 验证题用于区分原因，不模拟完整考试。
STOP & OUTPUT

停止与输出

  • 已明确目标、进度与主要错因。
  • 至少有一项行为证据或可靠历史记录。
  • 结论已能指导下一步行动。
  • 仍不确定时输出“初判＋验证任务”。

CPA 诊断口径与结果

总分只做概览，真正指导行动的是分项判断和错因证据。

学习覆盖度 · 20%章节完成情况和剩余内容。
知识掌握度 · 30%正确率、答题步骤和理解表现。
错误结构 · 25%概念、分录、计算、审题或整合。
知识稳定度 · 15%间隔测试和重复错误情况。
节奏适配度 · 10%剩余时间与每日投入是否匹配。
✓
结果必须包含
当前学习阶段、主要瓶颈、具体证据、诊断置信度、暂时不建议做什么，以及最多三个下一步动作。

五层技术结构

从用户输入到状态写回，CPA 场景复用原版 GenUI 技术链路。

01 INPUT对话与输入层自然语言、选择事件、答题步骤和用户修改。
02 ORCHESTRATION诊断与卡片策略层任务路由、候选卡生成、排序、停止和行动分流。
03 RUNTIME客户端 GenUI Runtime组件注册、Schema 校验、草稿保存、事件派发与局部 Patch。
04 SERVICES数据与模型服务层意图抽取、知识点映射、错因分类、题库与解释生成。
05 STATE状态与证据层学习画像、行为记录、来源、时间、置信度和任务接力。
02

CPA 场景模块映射

原有基础设施继续保留，只补充下列领域服务和策略配置。

模块主要职责运行方式关键约束
Intent & Field Extractor从自然语言中提取科目、章节、问题和决策诉求。模型抽取后经 Schema 校验。不得把推断当作用户已确认事实。
Learning Profile Store读取进度、正确率、错题、考试时间和每日投入。按来源、时间与置信度合并。历史信息过期时必须重新确认。
Card Policy Engine生成候选卡并按信息价值排序。规则评分＋模型候选生成。一次只突出一张主卡，避免固定长问卷。
Question Bank & Mapper选择能区分错因的最小验证题。知识点、题型与难度标签召回。验证题用于诊断，不替代完整模考。
Diagnostic Rule Engine计算分项诊断、停止条件和行动路由。确定性规则控制分值与边界。信息不足时不得输出虚假精确分数。
Model Explainer将规则结果转成用户可读的原因说明。绑定证据后生成自然语言。每项结论必须可回溯到来源。
State Writer将确认、答题和行动结果写回画像。通过提交门控产生版本化状态。草稿、系统推断与用户确认必须分层存储。

SCHEMA SAFETY安全渲染只渲染注册组件，卡片字段通过 JSON Schema 校验。
